## 二、资产包结构与格式规范

所有原始素材均已存放在工程的 `videos/` 目录下，文件命名遵循标准命名法则（同时配备中英双语字幕）：

```
videos/
 ├── <timestamp>_haohmaru_vs_<opponent>_VICTORY.mp4            # 60 FPS 高清对局视频
 ├── <timestamp>_haohmaru_vs_<opponent>_VICTORY_zh.srt         # 中文标准 SubRip 字幕
 ├── <timestamp>_haohmaru_vs_<opponent>_VICTORY_en.srt         # 英文电竞解说 SubRip 字幕
 ├── <timestamp>_haohmaru_vs_<opponent>_VICTORY.srt            # 默认字幕轨 (中文字幕向后兼容)
 └── <timestamp>_haohmaru_vs_<opponent>_VICTORY_commentary.json # 包含中英双语的毫秒级时间轴与元数据
```

### 2.1 视频技术参数
| 参数项 | 参数值 | 说明 |
| :--- | :--- | :--- |
| **视频编码** | H.264 / AVC (High Profile) | 兼容市面上所有主流剪辑软件 |
| **像素格式** | `yuv420p` | 标准 8-bit 色彩，避免导入时偏色或黑屏 |
| **帧率 (FPS)** | **59.19 FPS** (60 FPS 模式) | SNK NeoGeo 原生基准时钟 |
| **画面比例** | 4:3 街机原生像素比例 | 适合做怀旧街机边框或分屏对比包装 |
| **音频参数** | AAC 立体声，44.1 kHz，128 kbps | 完整录制原汁原味的游戏音效与打击声 |

### 2.2 字幕与元数据参数
- **`.srt` 文件**：UTF-8 编码，包含准确的毫秒级入点与出点时间码，可直接拖入视频轨上方的字幕轨；
- **`.json` 文件**：包含机器事件级细粒度数据（如开局 `MATCH_START`、立回攻防 `MID_COMBAT`、局间 `INTERMISSION`、终结一击 `KO_FINISH`、战后收刀 `CELEBRATION_SHEATHE`、饮酒大笑 `CELEBRATION_QUOTE` 等）。剪辑师可根据 JSON 中的时间范围，快速定位**刀剑命中、重斩击飞、裁判判定**的关键高潮帧。

## 三、剪辑软件导入与对齐操作指南

### 3.1 Adobe Premiere Pro 导入指引
1. **新建序列**：
   - 模式选择自定义：时基设置为 **59.94 帧/秒** 或 **60.00 帧/秒**；
   - 分辨率推荐设为标准 1080p（`1920 x 1080`，16:9）；
2. **导入视频与画面构图**：
   - 将 4:3 街机视频置于画面中心；
   - 两侧黑边区域可做**动态高斯模糊背景**（复制一层视频轨，放大铺满底层并添加高斯模糊 50，降低不透明度至 40%）；
   - 或者在左/右侧放置“AI 算法决策状态看板”、“当前对局比分卡片”；
3. **导入字幕 (`.srt`)**：
   - 直接将 `.srt` 文件拖入时间轴，Premiere 会自动创建专用字幕轨（Captions）；
   - 样式设置：建议使用粗黑体（如“思源黑体 Heavy”或“方正正粗黑”），字号 48，白色文字 + 2像素黑边 + 微弱投影，放置于画面底部（安全区内）。

### 3.2 Final Cut Pro / DaVinci Resolve / 剪映专业版导入
- **剪映专业版**：点击“文本” -> “智能字幕” -> “导入字幕 (SRT)”，选择对应 `.srt` 即可瞬间完成字幕上屏；
- **达芬奇 (DaVinci)**：将 SRT 文件直接拖入 Edit 工作区的字幕轨道，在 Inspector 中调整文本样式。

## 四、专业分镜脚本与后期特效建议

剪辑师在制作整套对战视频集锦（或单场对决精剪）时，可参考以下分镜节奏设计：

```
[0:00 ~ 0:45] 片头引入：科技风解说 + 机器学习训练演化快速蒙太奇
[0:45 ~ 0:50] VS 画面：角色双方对阵定格海报 (霸王丸 VS 目标对手)
[0:50 ~ 1:05] 第一局 (Round 1)：实机对战 + 同步字幕解说
[1:05 ~ 1:12] 第一局击杀瞬间：0.5x 慢动作特写 + 画面短暂闪白/红光震动
[1:12 ~ 1:18] 局间过渡：裁判举旗一本 + 双方血条回灌
[1:18 ~ 1:35] 第二局 (Round 2)：对手疯狂反扑 + 霸王丸核心确反重劈 KO
[1:35 ~ 1:45] 战后定格：收刀入鞘、大笑饮酒 + 终场大比分结算画面
```

### 4.1 高能高潮点特效包装建议
1. **重斩终结（KO 瞬间）**：
   - 在 JSON 标注的 `KO_FINISH` 时间点，画面的最后一记重斩（大劈）命中时，添加 **0.2 秒画面卡顿（Freeze Frame）** 或 **局部镜头推进放大 115%**；
   - 叠加**剑气音效（Whoosh / Slash SFX）**，放大街机打击感；
2. **AI 决策可视化 HUD（提升极客感）**：
   - 在画面右上角或左下角制作一个半透明科技风格浮窗，展示 AI 正在实时执行的意图：
     - `AI 意图: [升龙弧月 / ANTI_AIR]`（拦截跳击）
     - `AI 意图: [确反重击 / PUNISH]`（抓破绽）
     - `AI 意图: [重斩砍杀 / SLASH]`（输出爆发）
3. **血条高能警报**：
   - 当对手血量低于 20% 时，画面边框可加入微弱的红色呼吸光晕（Vignette Pulse），提示即将完成斩杀。

### 7.1 四类典型场景：别人拿到这些导出视频后怎么用？

#### 场景 A：直接观赛 / 汇报演示（零门槛播放）
- **推荐播放器**：PotPlayer、VLC、MPV 或 Windows 媒体播放器。
- **自动挂载双语字幕**：将 `.mp4` 与同名的 `_zh.srt` / `_en.srt` 放在同一目录即可；播放时在字幕菜单切换中文或英文解说轨，即可直接用于项目路演、技术分享或教学演示。

#### 场景 B：自媒体发布与一键硬烧字幕（B站 / YouTube / 抖音 / 视频号）
部分平台不支持外挂 `.srt`，可直接用 FFmpeg 一行命令将字幕烧录进画面（保留 60fps 与原画质）：
```powershell
# 1. 硬烧中文字幕（适合 B站 / 抖音 / 视频号）
ffmpeg -i "20261123_133024_haohmaru_vs_mizuki_VICTORY.mp4" `
  -vf "subtitles='20261123_133024_haohmaru_vs_mizuki_VICTORY_zh.srt':force_style='FontName=Microsoft YaHei,FontSize=20,Outline=2'" `
  -c:v libx264 -crf 18 -pix_fmt yuv420p -c:a copy "mizuki_zh_burnin.mp4"

# 2. 硬烧英文字幕（适合 YouTube / X / Reddit）
ffmpeg -i "20261123_133024_haohmaru_vs_mizuki_VICTORY.mp4" `
  -vf "subtitles='20261123_133024_haohmaru_vs_mizuki_VICTORY_en.srt':force_style='FontName=Arial,FontSize=18,Outline=2'" `
  -c:v libx264 -crf 18 -pix_fmt yuv420p -c:a copy "mizuki_en_burnin.mp4"
```
- **批量拼装 16 人连播合集**：可参考 [09_合集视频制作实战复盘_脚本参数与踩坑手册.md](./09_合集视频制作实战复盘_脚本参数与踩坑手册.md) 中的 `concat` 滤镜与双语片头脚本。

#### 场景 C：基于 `_commentary.json` 自动切高光短视频（程序化剪辑）
每部视频配套的 `*_commentary.json` 均记录了精确的 `start_sec` / `end_sec` 与事件标签（如 `KO_FINISH`、`CELEBRATION_SHEATHE`、`CELEBRATION_QUOTE`），二次开发者或剪辑自动化脚本可直接解析 JSON，自动截取每场对决最后 15 秒的“绝杀 + 收刀结算”做成 16 连杀集锦：
```python
import json, subprocess

meta = json.load(open("20261123_135611_haohmaru_vs_sieger_VICTORY_commentary.json", encoding="utf-8"))
ko_events = [s for s in meta.get("segments", []) if s.get("event_type") == "KO_FINISH"]
if ko_events:
    t0 = max(0.0, ko_events[-1]["start_sec"] - 3.0)
    subprocess.run([
        "ffmpeg", "-y", "-ss", f"{t0:.2f}",
        "-i", "20261123_135611_haohmaru_vs_sieger_VICTORY.mp4",
        "-t", "15", "-c", "copy", "sieger_ko_highlight.mp4"
    ])
```

#### 场景 D：AI 多模态研究与离线强化学习数据集复用
- **视觉-动作对齐**：MP4 视频帧（60 FPS）与 `models/experts/vs_<opponent>.json` 及录制日志对齐，可用于视觉端到端策略（Image-to-Action Behavior Cloning）训练。
- **视频理解 / 电竞解说评测**：MP4 + `_commentary.json`（含中英双语解说文本、比分、回合切换时间戳）可直接作为多模态大模型（VLM）的格斗游戏解说生成 Benchmark。
- **本地重新复现/定制录制**：拿到本开源发布包后，配置好 `MAME_DIR` 环境变量与 Python 环境，运行 `.\record_video.ps1 -Target mizuki -Mode bo3 -Speed 1` 或 `.\record_video.ps1 -All` 即可在任意机器上 100% 复现或重新生成高码率素材。
